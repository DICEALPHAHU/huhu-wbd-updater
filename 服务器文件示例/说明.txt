============================================================
  服务器上要放的三个文件（示例） —— 糊糊爆破模式客户端更新器
============================================================
把这三个文件放在 DownloadServer 指向的地址的根目录下，例如
  http://110.42.109.54:8080/version.json
  http://110.42.109.54:8080/note.json
  http://110.42.109.54:8080/alphahu.json

三者关系：
  version.json  → 只放版本号，程序靠它判断“有没有更新”
  note.json     → 更新公告，显示在面板上（会下载并保存在 HuhuUpdate 里）
  alphahu.json  → 文件更新清单，写各目录的包地址（只临时下载，用完即删）

------------------------------------------------------------
1) version.json
------------------------------------------------------------
{
  "version": "1.0.0"
}
  · 版本号随便什么字符串都行（1.0.0、20260917、v3 都可以），
    只要和上一次不同，程序就认为有更新。

------------------------------------------------------------
2) note.json
------------------------------------------------------------
{
  "notes": "本次更新内容：\n1. 新增 XXX 模组\n2. 修复 XXX 崩溃问题\n\n更新时间：2026-09-17"
}
  · 换行必须写成 \n（反斜杠+n），不能直接在字符串里敲回车，否则 JSON 会报错。
  · 也支持直接放纯文本（不写 JSON 也行）。
  · 也支持 {"note": "..."} / {"content": "..."} / {"text": "..."}。

------------------------------------------------------------
3) alphahu.json —— 四个目录 + 全量包地址
------------------------------------------------------------
{
  "full_url": "https://你的直链地址/full.zip",
  "mods":   { "version": "1.0", "url": "https://你的直链地址/mods.zip" },
  "config": { "version": "1.0", "url": "https://你的直链地址/config.zip" },
  "tacz":   { "version": "1.0", "url": "https://你的直链地址/tacz.zip" },
  "resourcepacks": { "version": "1.0", "url": "https://你的直链地址/resourcepacks.zip" }
}
  · full_url 是「方式二 全量更新」用的整包地址（整个客户端根目录的 zip）。
    界面选「方式二」时就会下它；不填的话方式二会提示缺少全量包。
  · 每个目录的 version 与客户端本地记录一致 → 该目录不下载、不覆盖。
  · 只改了 mods？把 mods.version 改成 1.1，其它目录 version 保持不动，
    程序就只会下 mods.zip。
  · 不想更新某个目录 → 把那一项删掉即可。
  · 可选：加上 "overall_version": "1.0.0" 可以给全量更新加一道版本判断
    （没加也不影响，界面上的版本判断由 version.json 负责）。

------------------------------------------------------------
以后每次发新版的标准操作（三步）
------------------------------------------------------------
  1. 上传改动过的 zip（例如 mods.zip）
  2. 改 alphahu.json：把改动目录的 version 改掉（没改的目录不要动）
  3. 改 version.json：把版本号改成新的（例如 1.0.0 → 1.0.1）
  → 客户端下次打开就会显示“发现新版本”，点“检查/应用更新”即可。

------------------------------------------------------------
包的内部结构
------------------------------------------------------------
  mods.zip 里放的就是 mods 目录里的文件（直接放文件，或包一层 mods/ 都行）
  config.zip / tacz.zip / resourcepacks.zip 同理
  full.zip（方式二用）里放整个客户端根目录（.minecraft、PCL 等），
    程序会跳过正在运行的更新器自身，避免文件占用报错。
